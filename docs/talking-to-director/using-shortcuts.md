# Composer commands and shortcuts

In Composer, type **/** in the caption area to open the available command menu. Choose from the options shown for that business and task. The menu is the useful reference; old lists of dozens of Director commands do not describe the current product.

## Use a command carefully

1. Select the right business and account.
2. Put the text or approved source material in place.
3. Choose the available command and supply what it requests.
4. Read the result and any error or limitation.
5. Apply the result deliberately, then review and save the draft.

An editing suggestion can change meaning even when it improves readability. Recheck claims, names, links and platform variants. Health suggestions remain subject to the same review and release checks as handwritten copy.

For recurring approved wording, use [post templates](../creating-content/post-templates.md). For repeated tags, use [Hashtag Manager](../creating-content/hashtag-groups.md). Those are saved content tools, rather than commands that promise an entire campaign or automatic publication.
