# Using Shortcuts (Slash Commands)
*Type / to see 65+ instant actions*

Slash commands are shortcuts that make it faster to ask for common things. Type / in the chat box and a list of available commands appears.

## How to use them

1. Click in the chat input box.

2. Type / (forward slash).

3. A dropdown appears with all available commands.

4. Keep typing to filter — e.g. /blog narrows the list.

5. Click a command or press Enter to select it.

6. The command turns into a natural language message and sends automatically.

## Most popular shortcuts

Here are the ones people use most:

1. /post — Write a social media post

2. /blog — Write an SEO-optimised blog article

3. /fill — Auto-generate 2 weeks of content

4. /audit — Run a full marketing audit

5. /design — Create a graphic in Canva

6. /video — Create an AI avatar video

7. /calendar — See your scheduled posts

8. /help — Show what the Director can do

## You do not need shortcuts

Shortcuts are optional. You can always just type naturally — "write me a LinkedIn post about our new service" works just as well as /post. Shortcuts just save time once you know what you want.
