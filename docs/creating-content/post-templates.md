# Post Templates
*Reusable caption templates with fill-in variables*

Post templates let you create reusable caption formats with variables like `{product}`, `{date}`, and `{brand}` that get filled in each time you use the template.

## Using a template

1. In the Post Composer, click the "Templates" button

2. Browse available templates and click one to select it

3. Fill in any variables (product name, offer details, etc.)

4. Preview the final caption and click "Use Template"

> **Tip:** Templates are per-brand, so each of your brands can have its own set of reusable formats.
