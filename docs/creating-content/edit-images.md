# Edit media and keep the original

Open **Media** and inspect the asset belonging to the intended business. Keep the original file: a finished edit should become a separate version that can be compared or replaced without losing its source.

The current native editor is centred on the supported media and video controls shown in the workspace. It is not a promise that every image has a full photo-retouching panel. Use the available controls or agree a separate design edit with NRS.

## Before using an edit

Check the crop, legibility, logo, colours and any people or products shown. Watch or inspect the rendered output, rather than relying only on an editing preview. Where a render is queued, wait for a playable or viewable result before attaching it for release.

An asset attached to a post must belong to that business. File an unfiled upload deliberately; do not reuse another client's asset because it appears in a broad library view.

For advanced Canva work, read [its current availability](../video-and-design/design-with-canva.md). Editing a health image does not resolve whether its use or implication is appropriate.
