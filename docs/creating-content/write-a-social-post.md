# Write a social post

Open **Composer** and confirm **Posting as** is the intended business. Select only the accounts meant to receive this post.

1. Write the shared caption using approved facts. Check product and service names rather than guessing.
2. Add media from the appropriate business library. An unfiled asset needs to be filed before release.
3. Review each platform tab. Editing a platform version leaves the shared wording separate.
4. Choose the format and options offered for each selected account.
5. Inspect the preview, character limits, media warnings and compliance findings.
6. Choose **Save draft** to retain editable work.

Use **Templates** or **Hashtag Manager** when appropriate. An AI suggestion is optional; read and apply it deliberately.

When the draft is ready, follow the agreed [approval process](approve-posts.md) and [scheduling steps](../publishing/schedule-a-post.md). A saved draft is not on social media. For a health business, the responsible person must review the actual claim and visual context, even when the automated check shows no issue.
