# Use Hashtag Manager

In Composer, open **Hashtag Manager** from the hashtag control. It works with the selected business so reusable tags stay with the correct client.

## Make a useful group

Give the group a recognisable name, such as “local opening hours” or a real campaign name. Enter the tags using the separation shown in the form, then save. Review the saved group before inserting it into a caption. Remove groups that are outdated rather than leaving several indistinguishable versions.

Tags still need to fit the actual post. Check spelling, product names, location and platform limits. Do not use tags that imply a treatment outcome or medicine promotion simply because another account uses them.

A saved group is a writing convenience. It does not promise reach or a ranking position, and inserting it does not publish the post. Recheck each platform's final text and [save or schedule](../publishing/schedule-a-post.md) through the ordinary review path.
