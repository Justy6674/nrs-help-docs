# Use From VS Code
*Connect your agency to Visual Studio Code with the Cowork extension*

If you or your developer uses VS Code (a code editor), the Cowork extension lets you talk to your Director right inside the editor. This is handy for teams that build websites or apps alongside their marketing.

## What you need

You will need an API key from your NotRealSmart account. Think of an API key as a special password that lets other apps connect to your agency securely.

1. Log in to NotRealSmart at notrealsmart.com.au.

2. Go to Settings (click your profile picture, then Settings).

3. Find the "API Keys" section and click "Create New Key".

4. Give it a name like "VS Code" and copy the key. It starts with nrs_sk_ — save it somewhere safe.

> **Warning:** Your API key is shown only once. If you lose it, you will need to create a new one.

## Setting up VS Code

Once you have your API key, add it to the Cowork extension settings.

1. Install the Cowork extension from the VS Code marketplace.

2. Open Cowork settings (Cmd+Shift+P on Mac, Ctrl+Shift+P on Windows, then search "Cowork").

3. Add a new MCP server with the URL: https://www.notrealsmart.com.au/api/mcp

4. Paste your API key as the Bearer token.

5. Save and restart VS Code.

## Using it

You can now ask Cowork to use your NotRealSmart tools. For example: "Write a blog post for my brand using NotRealSmart" or "Check my social media analytics." The extension handles everything behind the scenes.
